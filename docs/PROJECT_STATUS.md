## 5. 不足

1. **异常规则泛化差。** 盲测 6 道异常题只过 1 道。阈值是固定的（如有息负债率同比 +8pp），与分析师判断不一致：比亚迪负债跳升、宁德时代和隆基减值都没触发。应按行业校准。
2. **golden 满分说服力有限。** golden 题按系统同一套规则构造，满分只证明规则实现正确。泛化只能看 blind，而 blind 只有 30 题、一个出题人，出题人也是模型。
3. **在线评测没有置信区间。** 每个架构只跑一次；两两对比只有 10 题、一个裁判模型。
4. **在线结果不是最新代码。** 11-10 跑的在线矩阵早于 11-11 的规则修正，没重跑。
5. **B4 成本高。** 单题约 ¥0.056、103 s，是 B3 的 7 倍成本、5 倍耗时；硬指标上只多出 5 道异常归因题。
6. **B3 与 B2 在真实模型下通过题完全相同。** ReAct 循环没有带来硬指标收益。
7. **模型 Rubric 不可信。** B0 无证据却拿到最高 Rubric 均分 0.753。现在只把结构化 Rubric 和两两对比用于判断。
8. **成本单价未核实。** 按 ¥2 / ¥8 每百万 tokens 估算，没对照硅基流动账单。
9. **五粮液 2025 年数据被数据商大幅改写，原因未查明。** 系统按修订版本处理，不会提前看到改写值。

## 6. 遇到的问题与处理

| 问题 | 处理 |
|---|---|
| AKShare SSL 被拦，Baostock 登录卡死 | 改用东方财富 F10 + 巨潮 + Yahoo；noblechang/a-share-data 只有行情且 1.9 GB，放弃 |
| PDF 版面模型（ONNX）原生崩溃 | 改用 PyMuPDF `find_tables(use_layout=False)` |
| 数据商数值与原始财报不一致 | 差异 >0.3% 且更新晚于公告 30 天以上，判为重述：原值在公告日可见，改写值在更新日可见 |
| 硅基流动余额耗尽（402）导致半数题退回模板 | 加 fail-fast；评测可续跑；结果剔除退化题后补跑 |
| 模型自评说 LLM 辩论更差，独立裁判说更好（8:0:2） | 不再用自评做决定；改用独立裁判两两对比 + 空白对照（4:1:5） |
| 绝对 Rubric 随裁判模型漂移（0.784 vs 0.74） | 绝对 Rubric 不再决定通过与否 |
| B0 不引用证据也能通过开放题 | 加证据门槛：非拒答题引用有效率须 ≥80% |
| B2 报“60 题 LLM 调用失败” | 是误报：占位记录标签不一致，已统一 |
| 规划器把“尚未披露的报告期”换成最新期回答 | 改为拒答（盲测发现） |
| 茅台例行关联交易被打成治理风险 5/5 | 只认重大关联交易；例行预计、财务公司存款说明、制度文件不触发 |
| 茅台应收账款小基数翻倍报高危 | 应收账款不足 TTM 营收 1% 时不报 |
| 公告摘录是法律声明套话 | 跳过声明，引用正文 |
| “最大回撤(1年)”被核验器当成野数字降级 | 核验器跳过指标名里的时间窗 |
| PowerShell 改文件破坏 UTF-8 中文 | 用 git 恢复，改用编辑工具 |
| 推送命令被策略拦截 | `git push origin main:init` 单独执行 |
