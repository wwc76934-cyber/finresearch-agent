| 宁德时代 300750.SZ | 电力设备/电池 | [md](300750_20260506_B4.md) | 存货周转天数 87 → 115 天（MEDIUM） | 估值 5、波动 3、偿债 2、其余 1 | 127 s | ¥0.065 |

每份报告都有：公司概况、看多/看空论点（含隐含假设）、4 条可检验的证伪条件（阈值本身是 MetricRecord）、六维风险矩阵、数据局限声明，以及 `claim -> evidence -> source` 引用。`.json` 里有完整 trace、核验日志和辩论记录。

PDF 不进仓库（.gitignore），加 `--pdf` 在本地生成。

复现：

```bash
python scripts/run_research.py 300750.SZ 2026-05-06 --out reports/cases --pdf
```

生成这些案例时发现并修复的通用缺陷（都不针对某一家公司）：

| 现象 | 原因 | 修复 |
|---|---|---|
| 公告摘录是“董事会及全体董事保证……”套话 | 引用了公告开头的法律声明 | 跳过声明和“重要内容提示”，引用正文 |
| 茅台治理风险 5/5 | 日常关联交易预计、财务公司存款说明、关联交易制度都算成异常 | PRD 规则 7 是“重大”关联交易；例行文件不再触发（检测器和 Oracle 各自实现） |
| 茅台“应收账款同比 +112.8%”高危异常 | 应收账款不到营收 1%（0.1 天），小基数翻倍 | 应收账款低于 TTM 营收 1% 时不触发（检测器和 Oracle 同改） |
| “若应收账款周转天数升至 0.1 天以上（当前 0.1 天）” | 阈值只按 +10% 算 | 阈值取 max(×1.1, +5 天) |
| “最大回撤(1年)”“PE 3年分位”被核验器判为野数字并降级 | 指标名里的“1年”“3年”被当成待核验数字 | 核验器跳过指标名里的时间窗 |
| MD&A 解释句是“□适用√不适用”表格标题或披露规则原文 | 关键词“原因”出现在表头里 | 去掉勾选框表头；去掉后不含解释词就跳过 |

旧的 `990001/990003/990005_20251231_B4.*` 是虚构实验室公司上的案例，保留作对照。
