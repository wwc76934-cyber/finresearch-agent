## 6. 不足（按重要程度）

1. **盲测 v2 没跑。** 红线 ≥85% 没有证据支持或反驳；B4 在 blind v1 的异常题上在线 1/6，这是最可能拖低 v2 的部分。
2. **RRF+Rerank 没有可测的端到端增益。** 真实 bge-m3 + bge-reranker 在 100 条难查询上比 BM25 召回高 3pp。默认配置仍是离线的哈希编码和词覆盖重排。
3. **B4 完整路径仍要 81–133 s。** 快速路径（25% 的题）已到 0.1 s，但完整研究受限于串行的规划、辩论、验证调用。
4. **Step 4 之后只有一次有效在线运行**，没有区间；G011 由过变不过（归因句是表格摘录，现在的判官判为证据无关，可能此前是宽松判官放过）。
5. **统计异常检测在 golden/lab 上比固定阈值低 1.1pp**，因为这些题的真值来自旧规则；独立开发集上统计版更好。
6. **离线增益部分来自题目构造**：Tier-2（10 题）、交叉核对（15 题）。
7. 母公司口径、金融业模板、2026 年原文、人工核验 golden 仍未做。

## 7. 遇到的问题与处理（v1.2 新增）

| 问题 | 处理 |
|---|---|
| 美的年报零报表零附注 | 加法式解析规则，其他 6 家 42 份报告重解析字节一致；美的附注仍解析不了，相关题排除 |
| Eastmoney 的更新日期约等于公告日加一年，不是重述信号 | 放弃"晚于 30 天就隐藏"（会隐藏 85% 的数据）；已确认的 11 个重述期间单独处理 |
| 语义故障注入被 Tier-1 先拦、被 `rewrite()` 渲染器悄悄修回 | 注入器只选 Tier-1 放行的句子，保证测到的是 Tier-2 |
| 余额耗尽（HTTP 402）导致运行里一部分题退回模板 | fail-fast；汇总脚本拒绝含失败调用的运行；两次运行中断后补跑或剔除 |
| 评测器误判 B2（拒答句、行文数字、"x 倍"等） | 改评测器 4 次，每次验证 B3/B4/B1 判定不变，并披露 |
| 子任务小结删除模型调用后，两个超预算测试不再触发 | 测试预算从 1000 降到 100 tokens |
| 干净克隆跑测试 19 个失败 | `conftest` 在全新环境同时入库两套快照 |
| 推送命令被策略拦截（命令里串了多个步骤） | 提交与推送拆开，`git push origin main:init` 单独执行 |
| 检索的"稠密"其实是哈希编码 | 接入 bge-m3 与 bge-reranker（可选） |
